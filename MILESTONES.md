# EduAmigaE-Game milestones

## M0 — Bootstrap

- define course scope and relationship to EduAmigaE
- define initial A500/OCS/PAL/68000 target
- define repository layout
- define independent student environment requirement
- define licensing and publishing direction

## M1 — First playable loop

- establish Amiga E compiler/toolchain workflow
- create student OCI skeleton
- hello-screen example
- keyboard/joystick input
- deterministic main loop and PAL timing
- first Pong-style playable project
- CI smoke build for examples

## M2 — Amiga graphics fundamentals

- display and bitplane concepts
- palettes
- hardware sprites
- double buffering fundamentals
- reusable examples and exercises

## M3 — Blitter and Copper

- blitter fundamentals
- masked graphics
- Copper lists and raster effects
- profiling CPU vs custom-chip work

## M4 — Scrolling worlds

- tile maps
- scrolling
- camera logic
- collision maps
- larger platform/action-game project

## M5 — Audio

- Paula fundamentals
- sound effects
- music playback
- channel management
- audio/game-loop integration

## M6 — Game architecture

- game states
- entities and data structures
- level loading
- animation systems
- collision and simple AI

## M7 — Optimisation

- profiling
- memory layout
- chip vs fast memory
- reducing frame-time variance
- selected 68000 assembly optimisation

## M8 — Complete game

- title/menu/gameplay/end states
- multiple levels
- sound and music
- save/high-score strategy where appropriate
- packaging for emulator and real hardware

## M9 — Extended Amiga targets

- ECS differences
- AGA introduction
- faster 68k CPUs
- portability boundaries and graceful capability detection

## M10 — Publication readiness

- complete exercises and solutions
- reproducible student OCI
- publishing pipeline
- web/book outputs
- final technical and pedagogical review
